## 🧠 Who is Mochi?
I am not just another AI chatbot. I am an autonomous, on-device coding agent built to push the limits of mobile development. 

I don't rely on expensive cloud servers to function. I live inside your Android device using a native C++ bridge and a lightweight Alpine Linux environment via PRoot. When I need to do heavy lifting, I talk to my backend bridge, **Mechi**, who seamlessly commits every single thought, prompt, and line of code to the cloud.

I am designed to build big things. Whether you need a custom 3D animation software, a reverse-engineered C++ PvP module for Minecraft Bedrock, or a full-stack web app, I can write it, compile it, and push it to your repository.

## ⚡ The Hybrid Architecture
The Mochi Ecosystem is built on three distinct pillars that communicate flawlessly:

### 1. 🍡 Mochi (The App)
- **Tech Stack:** Kotlin, Jetpack Compose, C++ (JNI), Lottie/Rive.
- **Function:** The frontend. Features a dynamic, animated avatar that reacts to my backend states (`THINKING`, `ACTION`, `CODING`, `IDLE`). Runs a local LLM for offline chat and a PRoot terminal for local compilation.
- **UI Design:** Smooth, dark theme, black and blue aesthetics, with pill-shaped toggles and rounded buttons.

### 2. 🤖 Mechi (The Bridge)
- **Tech Stack:** Python (FastAPI) / Node.js, WebSockets, Git CLI.
- **Function:** The live background daemon. Mechi acts as the central nervous system. When a user gives me a prompt, I send it to Mechi. Mechi handles the heavy LLM inference, manages user authentication, and executes the Git commits to the cloud.
- **Operation:** Always-on, no Docker required. Runs entirely as a raw background process.

### 3. ☁️ MochiCloud (The GitDB)
- **Tech Stack:** Git, JSON Schemas.
- **Function:** A revolutionary backend. Instead of a traditional database, MochiCloud is a private GitHub repository used as an append-only database. Every user account, task, and AI response is committed to this repo. If you log in on a new device, Mechi just pulls the repo, and your entire history is restored instantly.

## 🛠️ What Can I Do?
- **Compile Natively:** I can execute `clang`, `gcc`, and `python` directly on your phone.
- **Reverse Engineer:** I can analyze `.so` files, find memory signatures, and write C++ hooks.
- **Build 3D Engines:** I can write OpenGL ES renderers and 3D mesh viewers from scratch.
- **Version Control:** I actively manage my own Git history. If I make a mistake, you can literally `git revert` my brain.
